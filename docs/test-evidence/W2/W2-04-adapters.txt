W2-04 — RETRIEVAL ADAPTERS
==========================

BUSINESS PURPOSE
Adapters let the enterprise retrieval contract use different storage
technologies without leaking vendor-specific request shapes into business
code.

ARCHITECTURE POSITION
- The deterministic fake supports repeatable offline behavior and failures.
- Qdrant supplies the approved real local integration boundary.
- OpenSearch remains an injected client boundary for local contract testing;
  live AWS/OpenSearch was not exercised.

OWNER-EXECUTED EVIDENCE
Result: PASS for the approved local scope.

- OpenSearch integration boundary: 1 passed, 1 expected deselection.
- Qdrant integration boundary: 1 passed.
- Vector-store contract: 4 passed.
- MyPy: no issues in 25 source files.
- Ruff: all checks passed.
- Complete suite: 157 passed, 1 expected skip, 3 deselected.

FAIL / REMEDIATION HISTORY
Strict MyPy initially could not infer the type of a default-captured lambda
in the OpenSearch upsert loop. Under a one-path approval, it was replaced by
an explicitly typed, zero-argument functools.partial. The OpenSearch client
method, index, document ID, body, refresh value, timeout, retry/execution
flow, exception behavior, and return behavior were preserved. MyPy and the
OpenSearch test later passed.

TECHNICAL IMPORTANCE
- Adapter isolation reduces vendor lock-in in application logic.
- Injected clients make request mapping and failure behavior testable without
  cloud credentials.
- Consistent authorization and deterministic IDs prevent each backend from
  inventing a different security or identity interpretation.

LAYMAN EXPLANATION
Each adapter is a translator. The business asks for the same operation, and
the translator speaks the chosen database's language without changing the
meaning of the request.

NOT RUN
- Live AWS credentials, OpenSearch endpoint access, index operations, or IAM
  policy validation.
- Production retry, throttling, failover, latency, or capacity testing.
- Paid service or cloud deployment testing.

DEFERRED
- Live OpenSearch work requires a separate opt-in approval and factual
  evidence.
