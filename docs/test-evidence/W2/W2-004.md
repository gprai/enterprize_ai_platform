# W2-004 — Local retrieval, regression, rollback and teardown evidence

## Business outcome

W2-004 proves that approved local enterprise content can be ingested and retrieved through the bounded retrieval architecture while tenant authorization remains enforced. It also demonstrates a controlled regression exercise, restoration of the known-good behavior, exact collection removal and cleanup of task-owned local resources.

This is local engineering evidence. It is not evidence of a production deployment, live AWS/OpenSearch integration, production identity enforcement or regulatory compliance.

## Architecture position

The workflow connects the previously approved W2 ingestion and embedding contracts to Qdrant through the retrieval service. Qdrant remains on the Compose logical network `qdrant_internal`; it has no host-port publication. A one-shot, non-root test runner performs the approved real local retrieval phases from inside that network and uses the verified local MiniLM model artifacts.

In plain language, the model and vector database were exercised together inside an isolated local Docker network. The owner proved that approved users obtain relevant results, unauthorized tenant data remains inaccessible, the failure path can be demonstrated, and task-owned resources can be removed afterward.
