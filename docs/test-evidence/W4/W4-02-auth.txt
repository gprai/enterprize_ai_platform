BUSINESS PURPOSE

W4-02 separates trusted caller identity from untrusted query data. The API
accepts an injected asynchronous authenticator, validates the returned existing
AuthContext and denies access before protected AI work when authentication or
authorization fails. W4-001 adds no live identity-provider integration.

AUTHENTICATION CONTRACT

- The injected interface is equivalent to async authenticate(request) ->
  AuthContext.
- Ordinary tests use deterministic fake authenticators and synthetic local
  identities.
- The default authenticator fails closed with 503
  authentication_not_configured when no producer is configured.
- Missing authentication returns 401 authentication_required.
- Invalid authentication, an invalid AuthContext or an expired context returns
  401 authentication_invalid.
- Explicit operation denial returns 403 authorization_denied.
- Authenticator exceptions are normalized without exposing raw exception text.

AUTHORIZATION ORDERING AND DOWNSTREAM ENFORCEMENT

- Media type, raw body, JSON and request-schema validation occurs before
  authentication-dependent RAG work.
- Authentication and explicit operation denial occur before RAG, retrieval,
  provider, graph or tool invocation.
- Existing downstream tenant, clearance, role, group and ACL enforcement
  remains unchanged.
- An authenticated caller with no authorized evidence receives HTTP 200 with
  the existing no_authorized_evidence abstention.
- An existing vector-store authorization denial remains HTTP 403 with its
  existing safe code.

UNTRUSTED INPUT AND REQUEST IDENTITY

- Request JSON contains only query: str and cannot construct or override
  subject, tenant, roles, groups, clearance, issuer, audience, expiry,
  authorization policy or trusted request identity.
- Inbound X-Request-ID, X-Correlation-ID and X-Forwarded-* values are not
  trusted as the server-generated request ID.
- Every W4-enabled response instead receives a new server-generated UUIDv4.
- W4-001 adds no trusted-proxy, CORS, public-binding or proxy-identity policy.
