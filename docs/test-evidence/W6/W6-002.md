- `w6-002.observability.v1` adds strict evidence and handover records that preserve cloud and deployment activity as `NOT RUN`.

- Telemetry schemas allow approved finite attributes and reject narrative content, credentials, tenant identifiers, prompt content, answer content, and evidence content.
- The default rollback profile disables the exporter and background worker.

- Telemetry is schema-bound and content-free. Tests reject unapproved narrative fields and scan deployment-readiness artifacts for credential and content field names.

- The proposed AWS path requires private endpoints, EKS Pod Identity, least privilege, no static credentials, approved retention, and an explicit live cost cap.
