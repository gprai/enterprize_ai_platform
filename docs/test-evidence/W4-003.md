## Business purpose and delivered boundary

W4-003 provides safe, vendor-neutral observability for the API, RAG,
retrieval and bounded-agent workflows without exporting protected business
content. The default application remains offline and side-effect free through
`NullTelemetryRuntime`. An OpenTelemetry runtime is created only through
explicit application composition or deterministic test injection.

The application uses manual request instrumentation and creates a new local
root trace for each request scenario. It ignores inbound `traceparent`,
`tracestate`, baggage, request, correlation and forwarded identifiers. The
existing server-generated request ID is correlated only in safe spans/logs and
never becomes a metric label or authority source.

The implementation uses OpenTelemetry API/SDK `>=1.44,<1.45`; it adds no OTLP
exporter package or FastAPI auto-instrumentation dependency. Resource values
are restricted to the validated service name, repository package version and
validated application environment.

## Telemetry contracts

### Metrics

| Instrument | Type | Unit |
|---|---|---|
| `enterprise_ai.stage.executions` | Counter | `{execution}` |
| `enterprise_ai.stage.duration` | Histogram | `s` |
| `enterprise_ai.usage.tokens` | Counter | `{token}` |
| `enterprise_ai.retrieval.results` | Histogram | `{item}` |
| `enterprise_ai.agent.steps` | Histogram | `{step}` |
| `enterprise_ai.agent.tool.calls` | Counter | `{call}` |
| `enterprise_ai.telemetry.export.failures` | Counter | `{failure}` |
| `enterprise_ai.telemetry.dropped` | Counter | `{item}` |

Metric attributes are positive-allowlisted finite values: stage, operation,
outcome, approved terminal reason, approved safe error code, token type,
signal, drop reason and approved bounded prompt, graph and tool identifiers.
The finite metric-series upper bound is derived from the exact instrument,
enum and allowlist products. Request, trace, span, identity, approval, run,
query, source, document and chunk identifiers and arbitrary strings are
prohibited as metric labels.

### Spans, events and safe logs

Approved spans cover the API, authentication, authorization, guardrail, RAG,
retrieval, query/document embedding, vector search, LLM, agent controller and
graph stages, approval persistence/evaluation, tool execution and telemetry
export. Approved events are exactly `stage.completed`, `security.decision`,
`approval.decision`, `telemetry.export_failure` and
`telemetry.record_dropped`.

Structured logs use schema `w4-003.telemetry.v1`. Their strict, immutable
schema permits only timestamp, event/service identity, server request ID,
trace/span correlation, finite stage/operation/outcome values, approved safe
terminal/error codes, bounded duration/count fields and approved version
identifiers. Extra, incomplete, negative, non-finite, inconsistent or
unapproved values fail validation before any sink.

Raw prompt/query/answer text, retrieved content or identifiers, tenant and
subject identity, approval/run identity, tool arguments/results, credentials,
PII, provider envelopes, raw exceptions, stack traces and chain-of-thought are
excluded before processors, buffers, readers or exporters.

## Bounded runtime and collector planning boundary

- In-memory span capacity: exactly 512; drop oldest.
- In-memory safe-log capacity: exactly 512; drop oldest.
- Safe dropped-item and export-failure signals are bounded and content free.
- Application telemetry queue, retries and background workers: zero.
- File/socket spill: prohibited.
- Flush and shutdown deadlines: 1.0 second each.
- Export failure never changes a business or security result and never retries
  RAG, retrieval, provider, graph, approval or tool work.
- Cancellation propagates and starts no replacement work.

`configs/observability/otel-collector.local.yaml` is configuration-only. It
binds OTLP gRPC to `127.0.0.1:4317` and HTTP to `127.0.0.1:4318`, uses a batch
timeout of 1 second, batch size 64 and maximum size 64, and sends traces,
metrics and logs only to the local debug exporter. It contains no
`memory_limiter`, exporter sending queue, additional listener, Jaeger/cloud
destination, secret or environment substitution. Static validation passed;
collector execution, immutable image selection and runtime/schema
compatibility remain **NOT RUN**.
