## Business and architecture decision

The selected path is:

`model class + immutable artifact identity → approval/admission checks → provider-neutral route → Bedrock, SageMaker real-time, or explicitly justified EKS`

- Approved foundation models route to Bedrock.
- Approved custom or fine-tuned artifacts default to SageMaker real-time when
  managed hosting is justified.
- Structured models require a W7-004 admission reference before serving is
  eligible; SageMaker real-time is then the AWS-first default.
- EKS requires documented platform-control, GPU/multi-model, or latency
  evidence plus an explicit EKS approval reference.
- Ray Serve and Triton remain conditional future EKS choices. Neither was
  installed, implemented, or tested.

The rejected alternative is replacing Bedrock or provisioning every engine for
demonstration. The full decision and supersession rule are in
[ADR-019](../../adr/ADR-019-serving-architecture.md).

## Identity, interface, and failure contracts

`ArtifactIdentity` binds model class, artifact name/version, lowercase SHA-256
digest, source URI, license, approval state/reference, tenant scope,
classification, processing region, separate training/inference identity
references, and optional superseded digest. Strict Pydantic validation rejects
extra fields and malformed values. Canonical serialization uses sorted compact
UTF-8 JSON, producing a stable SHA-256 identity.

`InferenceProvider.infer` accepts `ServingRequest` and returns
`ServingResponse`. Payloads are defensively copied. Provider selection is
deterministic and has no discovery, dual-path compatibility, or silent
fallback.

Negative behavior is fail closed:

- non-approved artifacts are rejected;
- structured models without W7-004 admission are rejected;
- EKS conditions without an EKS approval reference are rejected;
- unauthorized, wrong-tenant, or mismatched-classification requests are
  denied before a provider should be called; and
- timeout, throttling, unavailability, malformed response, and validation
  failures have normalized error identities.

W8-001 defines the authorization check but does not integrate it into the
existing FastAPI/LangGraph call path. A future orchestrator must call it before
provider invocation; the local tests do not prove production wiring.
