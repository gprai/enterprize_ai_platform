private networking, KMS, S3 storage, metadata-only Secrets Manager inputs, IAM,

`ap-southeast-1`, Amazon Nova 2 Lite through
`global.amazon.nova-2-lite-v1:0`, Global Cross-Region processing, no automatic
model/provider/Region fallback, and synthetic non-production non-sensitive
data only.

the bounded implementation under owner review. This evidence is not a commit,
