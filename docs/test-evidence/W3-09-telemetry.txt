- Schemas are strict, immutable and `extra="forbid"`.
- Missing paired values, extra fields, unknown values, unapproved versions,
  negative counts, non-finite duration and inconsistent token totals fail.
- Span and log buffers accept only capacity 512 and drop the oldest item on
  overflow; safe drop signaling was verified.
- Null runtime selection and lifecycle are side-effect free.
- Enabled telemetry requires explicit injected composition.
- Exporter failure is normalized to safe `telemetry_export_failed`, leaves the
  business/security result unchanged and exposes no exception detail.
- Synthetic sentinels for prompt, answer/PII, evidence, tool argument,
  credential and exception detail were absent from spans, events, metrics,
  logs, test buffers and captured logging.
- Authorization denial occurred before graph, gateway, planner, status, store
  or tool work.
